# Rebase Fork onto Upstream v7.7.1 + Roll Out Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebase the `feat/multi-runners` fork branch onto upstream release tag `v7.7.1`, then rebuild the Lambda artifacts and roll the changes out to AWS via `terraform plan`/`apply`.

**Architecture:** Our fork is purely additive (6 commits, +2357/−0, almost all in new dirs `deployments/shared-runners/`, `images/`, `docs/superpowers/`; only `.gitignore`, `CLAUDE.md`, `README.md` touch existing root files). A dry-run rebase onto v7.7.1 replayed all 6 commits with **zero conflicts**. The valuable upstream changes are mostly Lambda TypeScript fixes (`#5152` scale-up `ec2:TerminateInstances` IAM, `#5062` negative-capacity guard, `#5143` webhook→EventBridge, ~20 dep security bumps) plus two small Terraform fixes (`#5156` pool role type, `#5120` job-retry memory/timeout wiring). Because our deployment consumes locally-built `*.zip` artifacts (default `lambda_zip = null` → `${path.module}/../../lambdas/functions/.../X.zip`, with `source_code_hash = filebase64sha256(...)`), the rebase alone does NOT ship the Lambda fixes — the zips must be rebuilt so `terraform plan` detects the code-hash change.

**Tech Stack:** git rebase, Yarn 4.16.0 (vendored in `lambdas/.yarn/releases/`, bumped from 4.3.1 by upstream `#5155`), Nx (`nx run-many --target=build --all`), Node.js 24 (repo pins `v24` in `lambdas/.nvmrc`; the shell defaults to v22 so `nvm use 24` is required), Terraform 1.14.x, AWS provider `>= 6.33`.

**Pre-flight facts (verified 2026-06-15):**
- Our branch `feat/multi-runners` @ `8d7d23d1` forked from upstream `v7.6.0` (`1d571996`).
- Latest upstream release tag: `v7.7.1` (`79c869f4`, 2026-06-11). `upstream/main` is 3 commits past it; we deliberately target the **tag** for reproducibility.
- Toolchain present: Terraform v1.14.6, node v22.17.0 on PATH (must switch to 24), `upstream` remote + tags already fetched.
- Lambda zips currently in tree are gitignored build artifacts: `lambdas/functions/{control-plane/runners,webhook/webhook,ami-housekeeper/ami-housekeeper,gh-agent-syncer/runner-binaries-syncer,termination-watcher/termination-watcher}.zip`.

**Rollback:** Before rebasing, Task 1 saves the pre-rebase SHA to a backup ref. If anything goes wrong, `git reset --hard refs/backup/pre-v7.7.1-rebase` (local) restores the branch; the remote is only force-pushed in Task 4 after the rebase is verified, and `origin/feat/multi-runners` history can be restored from the same backup SHA + `--force-with-lease` if needed.
